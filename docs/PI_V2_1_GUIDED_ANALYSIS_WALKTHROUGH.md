# PI V2.1 Guided Analysis — First-Time User Walkthrough

## Start an analysis

1. Launch PI and open **Guided Analysis**.
2. Enter the property address, then select **Research retained evidence**. PI checks saved Properties and retained research before offering any new provider request.
3. If a retained match appears, confirm the displayed address and select **Start Guided Analysis**. An unknown address instead offers **Research New Property** with expected request usage and cost shown before execution.

## Follow the seven steps

1. **Identify Property** — Confirm the intended address. A match is a preliminary research identity, not legal parcel verification.
2. **Property Research** — Review property characteristics, the as-is provider valuation, county/distress indicators, listings and open evidence gaps. Use **Continue** when ready or **Skip for Now** to leave a visible reminder.
3. **Comparable Sales** — Review reported Sale events separately from listings. Select only relevant sales, exclude unsuitable records when appropriate and record the reason for the decision. Selection never changes the resale assumption automatically.
4. **Seller & Property Evidence** — Enter mortgage, payoff, liens, delinquent taxes, occupancy and condition evidence when available. Leave missing information unknown; do not enter zero as a substitute.
5. **Financial Analysis** — Enter proposed purchase price, rehabilitation cost and resale assumption, then review modeled profit, ROI, cash-on-cash, MAO, break-even price and scenarios. Use **Duplicate** to preserve the current scenario before testing a different strategy.
6. **Risk Analysis** — Review the Most Likely values inherited from underwriting. Optionally populate editable illustrative ranges and select **Run Monte Carlo**. P10 is a lower simulated profit result, P50 is the middle result and P90 is a higher result under the entered assumptions; none is a prediction.
7. **Investor Reports** — Review completeness and unresolved questions. Select Opportunity Brief or Full Investor Package, save the revision, preview it and export the PDF.

## Save, resume and use Advanced mode

- **Save & Exit** saves a changed draft locally and returns to My Workspace.
- Open **My Workspace → Analyses / Deals** and select **Continue Analysis** to resume the same subject, evidence snapshot and scenario.
- The persistent summary identifies the selected property, evidence snapshot and scenario revision at every analysis step.
- **Open Advanced Workspace** exposes the complete expert navigation without creating another scenario. **Return to Guided Analysis** resumes the corresponding guided step with the same data.
- Unsaved drafts are browser-local. Save a scenario revision before clearing browser storage, using another browser profile or moving to another computer.

## Reading the status labels

- **Complete** means the user advanced through the step or produced the relevant result; it does not mean every diligence question is resolved.
- **Skipped for now** records intentional deferral and remains visible.
- **Research warning** identifies missing or uncertain evidence that should be resolved before relying on the analysis.
- **Saved revision** is an immutable reportable version. Later draft changes require another save.
