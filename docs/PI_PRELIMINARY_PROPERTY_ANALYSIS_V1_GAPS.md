## What still blocks real financial execution

| Required evidence / assumption | Minimum next deliverable |
| --- | --- |
| Acquisition | A supported proposed purchase price or explicitly attributed investor assumption; tax delinquency and assessed value are not substitutes |
| Valuation / ARV | An exact-subject, licensed valuation/comparable-sales package with valuation date, relevant sold comps and condition/renovation basis; distinguish as-is estimate from supported after-repair value |
| Condition / renovation | Property-specific condition evidence and scoped cost estimate, contingency rationale and schedule; beds/area/year alone do not establish scope |

| Investor/model policy | Attributed return hurdle, uncertainty ranges and dependence rationale; provider ranges are not probability distributions by default |
