# Property Intelligence V3.0 — Beta Onboarding Guide

This guide is prepared for the initial invited beta analyst. It becomes applicable only after the owner approves organization creation, invitation, complimentary credit grant and external beta activation.

## Sign in

1. Open the private Property Intelligence URL supplied by Workside Software.
2. Use the Firebase invitation/password-reset email to set your password.
3. Verify your email address.
4. Sign in. Access is limited to your own organization; Workside properties and other customers are not visible.

## Research a property and use credits

1. Select **Guided Analysis → Analyze New Property**.
2. Enter and review the property address.
3. Review the provider-cost warning and explicitly confirm research.
4. One analysis credit is used only when a new property receives a usable analysis. A failed lookup releases the reservation. Reopening the same normalized property, editing assumptions, attaching evidence and correcting reports do not use another credit.
5. Retained or cached evidence is reused when available. Do not make a second provider request merely to refresh unchanged information.

The initial beta allowance, when approved, is three one-time complimentary credits. It does not replenish automatically.

## Complete analysis and diligence

1. Review the seven Guided Analysis steps and enter underwriting assumptions.
2. In **Investor Reports**, open the interactive Investment Due Diligence Checklist.
3. For each item, add notes, assign responsibility, optionally set a due date, and mark it Open, Reviewed or Information unavailable.
4. Use **Open related section** to return to the relevant analysis area.
5. Save checklist progress. If another session has newer changes, reload rather than overwriting it.

## Attach supporting evidence

1. Select **Attach supporting evidence** from the exact claim or checklist item.
2. Upload a PDF/JPEG/PNG or select an existing document.
3. Malware scanning, content validation, private storage and SHA-256 integrity are enforced automatically.
4. A CLEAN scan means the file is safe to handle; it does not prove authenticity or accuracy.
5. Review confidentiality and redistribution permissions before selecting a document for an investor package.

## Finalize with unresolved information

1. Review the displayed Critical and Important unresolved items.
2. If information truly cannot be obtained in time, read and select the acknowledgment.
3. Select **Finalize Report with Disclosures**.
4. The final report records your display name, organization, timestamp and outstanding-item counts. Finalization is not verification, appraisal or investment endorsement.
5. Later changes require a new saved scenario/report revision; historical reports are not overwritten.

## Share a report

An Organization Administrator or authorized analyst can grant a specific immutable report to a Report Viewer. The viewer can list and download only explicitly granted reports and cannot research properties, edit underwriting, upload evidence or retrieve private appendix files independently.

## Buy credits

When Checkout is enabled, select the credit purchase action. Stripe displays the configured amount and currency. Property Intelligence grants credits only after Stripe sends a verified successful-payment webhook; reaching a browser success page alone does not grant credit. Canceled or failed payments do not add credits.

## Support

Contact Workside Software support with the property address, approximate time, and visible error code. Never email passwords, authentication tokens, private download URLs or sensitive source documents unless Workside provides an approved secure channel.
